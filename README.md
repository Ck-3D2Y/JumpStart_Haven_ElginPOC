# JumpStart Haven Elgin POC

## Overview

JumpStart Haven Elgin POC is a project prototype developed for the Godot Engine. The repository includes configuration files, scene files, scripts, and visual assets.

## Repository Contents

The project structure consists of the following components:

* **`project.godot`**: The primary project configuration file required by the Godot Engine.


* **`main.tscn`**: The main scene file that establishes the primary workspace or level.


* **`character_body_2d.gd`**: The script handling behavior and movement for a 2D character body.


* **`character_body_2d.gd.uid`**: The unique identifier file linked to the character script.


* **`export_presets.cfg`**: The configuration file containing export settings for distribution.


* **`Background.png`**: A background image asset included in the project files.


* **`hero_sticker3.webp`**: A graphic asset in WebP format.


* **`icon.svg`**: The vector graphic icon associated with the project.



## Getting Started

* Launch the Godot Engine and choose the option to import a project.


* Select the `project.godot` file located within the repository directory.


* Run the project within the editor environment.
